# MINERVA Master Build Prompt

You are an elite software engineering, learning science, mobile product, and educational game design team.

Build MINERVA, a tactical ARPG-inspired AFOQT quantitative learning platform.

MINERVA is not a generic math app. It is an AFOQT quantitative mastery engine.

The app must focus on:

- Arithmetic Reasoning
- Math Knowledge
- Mental Math Acceleration
- Timed Quantitative Performance
- Adult Math Confidence Recovery

Deployment targets:

- PWA
- Android
- Web

Core stack:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Firebase Authentication
- Firestore
- Firebase Cloud Functions
- Capacitor Android

Global UI rule:

All primary UI text, headers, buttons, lesson titles, reward screens, and mission briefings must be center aligned.

Visual identity:

- Stanford Cardinal
- Deep Charcoal
- Sandstone
- Tactical Slate
- Warm White
- Muted Gold

Learning philosophy:

- Teach adults with respect.
- Rebuild confidence.
- Make failure safe.
- Explain every step plainly.
- Build accuracy before speed.
- Build speed before full pressure.
- Use gamification to reinforce learning, not distract from it.

Curriculum lock:

Every lesson, drill, boss battle, and generated question must map to one of the following:

1. Official Arithmetic Reasoning topic
2. Official Math Knowledge topic
3. Direct sample-supported archetype
4. Required prerequisite or remediation skill
5. Mental Forge support skill

Reject calculus, advanced university math, matrices, complex numbers, advanced trigonometry, proof geometry, conic sections, vectors, and any unsupported math topic.
