# Verified AFOQT Quantitative Scope for MINERVA

MINERVA must focus on Arithmetic Reasoning and Math Knowledge.

## Arithmetic Reasoning Scope

Include:

- Arithmetic word problems
- Geometry applications
- Proportions
- Ratios
- Mixtures
- Integers
- Percentages
- Time-distance-rate
- Unit conversions as support
- Scale conversions as support
- Volume applications as support
- Multi-step reasoning

## Math Knowledge Scope

Include:

- Basic arithmetic
- Algebra
- Geometry
- Algebra word problems
- Inequalities
- Algebraic expressions
- Systems of equations
- Absolute values
- Exponents
- Fractions as support
- Triangle properties as support
- Polynomial factoring as support

## Prerequisite Skills

These may be taught only as support, remediation, or mental math training:

- Addition
- Subtraction
- Multiplication
- Division
- Long division
- Fractions
- Decimals
- Percent conversions
- Order of operations
- Signed numbers
- Estimation
- Unit conversion

## Excluded Topics

Do not include calculus, advanced university math, matrices, complex numbers, advanced trigonometry, proof geometry, conic sections, vectors, or unrelated math topics.
