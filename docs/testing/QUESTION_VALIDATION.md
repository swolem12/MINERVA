# MINERVA Question Validation

Every question must include:

- Question ID
- Section
- Scope classification
- Skill tags
- Difficulty
- Prompt
- Answer choices
- Correct answer
- Explanation
- Estimated solve time
- Common trap
- Prerequisites

Reject if:

- Off scope
- Ambiguous
- More than one correct answer
- No explanation
- Too advanced
- Not connected to Arithmetic Reasoning or Math Knowledge
- Invalid math
- Bad answer choices
